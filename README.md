# Daggerheart Dice for Owlbear Rodeo

Beautiful unofficial Owlbear Rodeo dice extension for Darrington Press's Daggerheart, based on the [Owlbear Rodeo Dice Extension](https://github.com/owlbear-rodeo/dice).

## Building

This project uses [npm](https://www.npmjs.com/) as a package manager.

To install all the dependencies run:

`npm install`

To run in a development mode run:

`npm run dev`

To make a production build run:

`npm run build`

## Project Structure

All source files can be found in the `src` folder.
